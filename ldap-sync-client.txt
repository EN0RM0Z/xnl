1️⃣ Получение токена для сервисного пользователя
curl -X POST "http://localhost:8080/auth/realms/master/protocol/openid-connect/token" ^
 -d "client_id=admin-cli" ^
 -d "username=ldap-sync" ^
 -d "password=Password123" ^
 -d "grant_type=password"


В ответе будет JSON вида:

{"access_token":"eyJhbGciOi...","expires_in":300,...}


Скопируйте значение access_token для последующих запросов.

2️⃣ Получение списка LDAP-провайдеров в Realm
curl -X GET "http://localhost:8080/auth/admin/realms/myrealm/user-storage" ^
 -H "Authorization: Bearer ACCESS_TOKEN"


ACCESS_TOKEN замените на полученный токен.
Ответ вернёт массив объектов, где providerId = "ldap" и есть поле id — это и есть PROVIDER_ID.

3️⃣ Запуск полной синхронизации LDAP
curl -X POST "http://localhost:8080/auth/admin/realms/myrealm/user-storage/PROVIDER_ID/sync" ^
 -H "Authorization: Bearer ACCESS_TOKEN" ^
 -H "Content-Type: application/json" ^
 -d "{\"action\":\"triggerFullSync\"}"

4️⃣ Запуск синхронизации только изменённых пользователей
curl -X POST "http://localhost:8080/auth/admin/realms/myrealm/user-storage/PROVIDER_ID/sync" ^
 -H "Authorization: Bearer ACCESS_TOKEN" ^
 -H "Content-Type: application/json" ^
 -d "{\"action\":\"triggerChangedUsersSync\"}"
